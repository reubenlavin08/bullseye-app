{# Recovery / "kick the scheduler" button — added 2026-05-07. Why it lives here on Home: If the app crashes or the scheduler thread dies between session restarts (rare but happens), watches go quiet and the user has no obvious way to nudge them back into running. Without this button users see "scanning every X" widgets reading sensible numbers but no new finds, and conclude the product is broken. Hidden when active_watches == 0 (the onboarding CTA above handles that case — first task is creating a watch, not polling). The button calls /api/watches/poll-now which runs coordinator_tick() per active watch through the same gates (slow-start, cooldown, circuit-breaker) so a click can't compound a Facebook block. Built-in rate limit on the endpoint caps it at one click per minute. #}
Use this if Bullseye seems quiet — it kicks every active watch through one poll cycle.
